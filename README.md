Detailed Project Description
Smart Automatic Door Using ESP32, PIR Motion Sensor, Servo Motor, and ThingSpeak
This project is an IoT-based smart door system designed to automate door opening and closing using an ESP32 microcontroller. A PIR (Passive Infrared) motion sensor is used to detect the movement of a person near the door. When motion is detected, the PIR sensor sends a signal to the ESP32.
The ESP32 processes this signal and controls a servo motor, which represents the automatic door. When a person is detected, the servo motor rotates to open the door. After a short period, the door returns to its original position when no further motion is detected.
The project also uses Wi-Fi connectivity to send motion information to ThingSpeak, an IoT cloud platform. The detected motion is recorded as data, allowing the user to monitor the system remotely through the ThingSpeak channel.
The complete system is first developed and tested using Wokwi, an online electronics simulator. This allows the ESP32, PIR sensor, servo motor, and IoT functionality to be tested without requiring physical hardware.
